# 《原神》「月谕圣牌」导出接口调研报告

> 结论：官方战绩（Battle Chronicle）的 **`role_combat`（幻想真境剧诗）** 接口返回体里的 **`tarot_card_state`** 就是完整的「月谕圣牌」收藏数据（22 张，含是否解锁与持有张数）。手机端在米游社 App 里打开该页面还能直接生成分享长图，这是官方原生的“一键导出”。
>
> 本文只记录**接口事实**（URL、参数、字段名、鉴权方式），不包含任何官方前端代码或第三方源码；所有推断均可按第 3 节的方法自行复核。

---

## 1. 核心接口：`role_combat`

### 1.1 请求

| 项目 | 内容 |
| --- | --- |
| 国服（米游社） | `GET https://api-takumi-record.mihoyo.com/game_record/app/genshin/api/role_combat` |
| 国际服（HoYoLAB） | `GET https://sg-public-api.hoyolab.com/event/game_record/genshin/api/role_combat` |
| Query 参数 | `role_id`（游戏 UID）、`server`（`cn_gf01` / `cn_qd01` / `os_usa` / `os_euro` / `os_asia` / `os_cht`）、`need_detail`（`true` / `false`） |
| 方法 | GET（官方战绩页前端即按此方式请求） |
| 鉴权 | 仅需**有效登录 Cookie**（国服 `ltuid_v2` + `ltoken_v2`/`ltoken`；国际服另可用 `account_id` + `cookie_token`）。社区文档记载：原神战绩类接口**当前已不再需要 `DS` 签名** |
| 建议请求头 | `x-rpc-app_version`、`x-rpc-language: zh-cn`、`User-Agent`、`Referer`（国服 `https://webstatic.mihoyo.com/app/community-game-records/`，国际服 `https://webstatic-sea.hoyolab.com/app/community-game-records-sea/`） |

**连通性实测**（无 Cookie 调用，验证接口真实存在）：

```
GET .../genshin/api/role_combat?role_id=100000000&server=cn_gf01&need_detail=false
→ HTTP 200  {"data":null,"message":"Please login","retcode":10001}

GET https://sg-public-api.hoyolab.com/.../role_combat?role_id=800000000&server=os_usa&need_detail=false
→ HTTP 200  {"data":null,"message":"Please login","retcode":10001}
```

即接口在线、参数正确，只差登录态。

### 1.2 响应中与「月谕圣牌」直接相关的字段

| 字段路径 | 含义 |
| --- | --- |
| `data.tarot_card_state.total_num` | 圣牌总数（22） |
| `data.tarot_card_state.curr_num` | 已解锁数量 |
| `data.tarot_card_state.list[]` | **22 张牌逐张数据**：`icon`（图标 URL，未解锁时为空）、`name`（牌名）、`is_unlock`（是否已获得）、`unlock_num`（持有张数，>1 表示重复、可用于交换） |
| `data.data[].stat.tarot_finished_cnt` | 本期完成的「圣牌挑战」数量 |
| `data.data[].stat.difficulty_id` | 难度：`4` = 卓越，`5` = **月谕模式** |
| `data.data[].detail.rounds_data[].is_tarot` | 该幕是否为圣牌挑战幕 |
| `data.data[].detail.rounds_data[].tarot_serial_no` | 该幕抽到的圣牌编号 |

### 1.3 为什么可以确认这就是官方接口

| 证据 | 说明 |
| --- | --- |
| 官方战绩页有专门的「月谕圣牌」路由 | 官方战绩 H5（`webstatic.mihoyo.com/app/community-game-records/`）内含 `/ys/role-combat`（幻想真境剧诗）与 `/ys/role-combat/tarot`（页面标题即“月谕圣牌”）两条前端路由 |
| 该页面取数用的就是 `role_combat` | 页面脚本以 `role_id` / `server` 作为查询参数请求 `…/genshin/api/role_combat`，并把返回体中的 `tarot_card_state` 直接作为页面数据源 |
| 收藏页字段与接口字段一一对应 | 页面展示的 `curr_num` / `total_num` / `list[].is_unlock` / `list[].unlock_num` 与接口返回同名同义 |
| 官方 App 内可一键出图 | 该页面在米游社 App 内会调用客户端截图分享能力生成长图，等价于“官方一键导出” |
| 国际服同款页面结构一致 | 国际服战绩页（`act.hoyolab.com/app/community-game-records-sea/`，页面标题 “Battle Chronicle \| HoYoLAB Tools”）同样有 `/ys/role-combat/tarot` 路由，字段与国服完全一致 |

本仓库的实现（`src/yysp_core.py`）只做 HTTP 调用与字段解析，**没有复制任何官方前端代码**。

## 2. 一键导出的三种落地方式

| 方式 | 是否需要登录 | 说明 |
| --- | --- | --- |
| ① 米游社 App →「我的」→ 战绩 → 幻想真境剧诗 →「月谕圣牌」收藏 → 分享/长图 | 已登录 App | **官方原生一键导出**（后端即 `role_combat`），产出长图 |
| ② 直接调 `role_combat` | 需要 Cookie | 拿到 22 张牌的结构化数据（图标/名称/是否解锁/持有数） |
| ③ 本仓库工具 | 扫码或 Cookie | 一键导出 JSON + 自包含 HTML（图标本地化，可打印成图） |

**限制与注意：**

* 圣牌**收藏数据只存在于账号服务端**，只能通过战绩接口取；游戏本地文件里只有卡牌定义（名称、图标），没有“你拥有哪几张”。
* 战绩接口要求目标账号在游戏内**开启战绩展示**（默认开启），否则可能返回空数据。
* Cookie 等同账号登录态，请勿外传；本工具只从输入框/环境变量读取，可选保存在本机用户目录。
* 这是**非公开文档接口**，请自行控制频率（建议 ≥ 5~10 秒/次），遵守米哈游用户协议，仅用于导出自己的数据。

```powershell
# 1) 官方战绩前端里能搜到接口路径与路由（只做事实核对，请勿再分发官方脚本）

#    在开发者工具 Sources 中搜索 role_combat / role-combat/tarot / tarot_card_state

# 2) 无登录态验证接口存在
Invoke-WebRequest 'https://api-takumi-record.mihoyo.com/game_record/app/genshin/api/role_combat?role_id=100000000&server=cn_gf01&need_detail=false' -UseBasicParsing | Select-Object -Expand Content

# 3) 有 Cookie 时一键导出
python src\export-lunar-arcana.py --cookie "ltuid_v2=...;ltoken_v2=..." --uid 123456789 --server cn_gf01 --out out
```

## 4. 工程实现与实测记录

* 核心：`src/yysp_core.py`（取数、解析、图标下载、HTML 渲染）
* 登录：`src/yysp_login.py`（米游社扫码登录 `createQRLogin` / `queryQRLoginStatus`，成功后从响应头 `Set-Cookie` 取登录 Cookie）
* 界面：`src/yysp_gui.py`（tkinter；同时支持 `--selftest` / `--guitest` / 命令行导出）
* 测试：`tests/selftest_pipeline.py`、`tests/test_gui_smoke.py`、`tests/test_qr_login.py`
