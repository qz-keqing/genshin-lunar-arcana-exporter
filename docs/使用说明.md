# 月谕圣牌导出器 · 使用说明

一个小工具：**扫码或 Cookie 登录 → 填 UID → 一键导出《原神》「月谕圣牌」收藏**（JSON + 可直接打印成图的自包含 HTML）。
数据来自原神**官方战绩接口** `role_combat › tarot_card_state`（幻想真境剧诗 · 月谕圣牌收藏）：不抓包、不改包、不读游戏内存。

---

## 1. 四种用法

| 方式 | 命令 |
| --- | --- |
| 图形界面（推荐） | 双击 `src\dist\月谕圣牌导出器.exe` |
| 命令行导出 | `月谕圣牌导出器.exe --uid 123456789 --cookie "ltuid_v2=…;ltoken_v2=…" --out out` |
| 自检（排查问题） | `月谕圣牌导出器.exe --selftest 自检日志.txt`（接口连通 + 扫码通道 + 导出管线） |
| 直接跑源码 | `python src\yysp_gui.py`（Python 3.9+，`pip install segno`） |

## 2. 首次使用流程

1. **登录**（两个页签任选其一）
   * **扫码登录（国服）**：点「获取二维码」→ 用**米游社 App** 扫码并确认 → 显示“登录成功”。
   * **粘贴 Cookie（国际服 / 备用）**：浏览器登录米游社或 HoYoLAB → `F12` → Network → 任选一个 `api-takumi-record` / `sg-public-api` 请求 → 复制 Request Headers 里的整条 `Cookie`（至少含 `ltuid_v2`、`ltoken_v2`）→ 粘进输入框 → 「使用这个 Cookie」。
2. **填 UID**：可以手填（游戏内头像处可见），也可以点「列出我的角色」自动填入。
   服务器按 UID 首位推断：1–4 → 国服·天空岛，5 → 国服·世界树，6 → 美服，7 → 欧服，8 → 亚服，9 → 港澳台。
3. **点「一键导出月谕圣牌」**：界面会逐张列出 22 张圣牌（已获得 / 未解锁 / 重复张数），并写出文件。
4. 点「打开 HTML 收藏页」查看效果；浏览器里 `Ctrl+P` 即可打印 / 另存为 PDF、图片。
5. 勾选「记住登录态」时，Cookie 会保存在本机 `%APPDATA%\YueYuShengPai\session.json`（仅当前用户可读）；不想要就取消勾选或点「清除登录态」。

## 3. 导出产物

```
<输出目录>/

```

## 4. 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| `[10001] 登录态无效或已过期` | Cookie 过期或复制不全；重新扫码 / 重新复制 Cookie |
| 接口成功但没有 `tarot_card_state` | 该账号还没解锁幻想真境剧诗，或游戏内【设置 → 其他 → 展示游戏内信息】关掉了 |
| 二维码已失效 / 已取消 | 二维码约 3 分钟内有效，重新点「获取二维码」 |
| 「列出我的角色」失败 | 该接口国服仍走 DS 签名，属**尽力而为**的便利功能；直接手填 UID 即可 |
| 图标没下载下来 | 只影响 HTML 里的图片，JSON 数据仍然完整 |
| exe 被杀软 / SmartScreen 拦 | PyInstaller 单文件程序的常见误报，可加白名单，或自行 `python src\yysp_gui.py` 运行 |
| 中文乱码 | 命令行模式先 `chcp 65001`；GUI 与输出文件不受影响 |

## 5. 关于「输入 UID + 密码登录」

* **官方登录账号是邮箱 / 手机号，UID 只是游戏内角色 ID，本身不能用于登录。**
* 米哈游的密码登录接口带**极验验证码 + 设备风控**，第三方软件无法合规地自动完成；任何号称“输账号密码就能登录”的第三方工具，实际上都在**收集你的账号密码**——这正是盗号的标准手法。
* 因此本工具只提供两条官方通道：**米游社 App 扫码**（推荐，不接触密码）与**粘贴 Cookie**（等价于登录态，随时可失效）。
* 工具全程不收集、不上传任何凭据：请求只发往 `*.mihoyo.com` / `*.hoyolab.com`，登录态只存在你本机。
